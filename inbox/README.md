# Inbox: timetable files that need a login to download

Drop the downloaded zip files (GTFS) into the folder for their country, keep their names, and tell Claude they're there.
Nothing in this folder is published (it's git-ignored).

- `at/` Austria: register free at https://data.mobilitaetsverbuende.at, download every "GTFS" dataset
  (Verkehrsverbund Ost-Region, Steiermark, Oberösterreich, Salzburg, Tirol, Vorarlberg, Kärnten).
- `hr/` Croatia: Pula (Pulapromet), Osijek (GPP Osijek) and Jadrolinija ferries, if their operators send the GTFS files.
- `sk/` Slovakia: Košice (DPMK) and Žilina (DPMŽ), if the operators send them.
